#  AquaAlerta

## Sistema Comunitario de Monitoreo y Reporte de la Calidad del Agua

**AquaAlerta** es un proyecto de proyección social que busca desarrollar una plataforma comunitaria para registrar, monitorear y dar seguimiento a problemas relacionados con la calidad del agua.

El proyecto surge a partir de una problemática identificada en nuestra comunidad, donde se ha observado la presencia de sedimentos y suciedad en el agua, incluyendo lo que localmente se conoce como **"capa rosa"**.

##  Objetivo

Desarrollar una herramienta tecnológica que permita documentar problemas relacionados con la calidad del agua, identificar los sectores afectados y generar información organizada que facilite el seguimiento y la gestión de posibles soluciones para la comunidad.

Actualmente el proyecto se encuentra en su fase de planificación y desarrollo inicial.
